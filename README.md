# 仁家科技 · 内部积分系统

单文件网页版积分管理系统。**HTML / CSS / JS 全部内联，无后端、无外部依赖、无需构建**，数据保存在浏览器本地。

## 直接使用

双击 `index.html` 用浏览器打开即可。

### 管理员密码

管理员密码为**公司统一固定密码**，任何电脑 / 浏览器都用同一个口令：

1. 点右上角「切换身份」
2. 输入管理员密码 → 点「进入管理员模式」（或直接按回车）

- 口令**不保存在浏览器里**，所以换浏览器、清缓存、换电脑都不受影响，也不会随数据导出 / 导入变化。
- 源码里**不写明文口令**，只存它的哈希常量（`ADMIN_HASH`），仓库即使公开托管也不会直接暴露口令。
  - 更换口令：运行 `pwdHash("新口令")`，把结果替换 `ADMIN_HASH` 即可。
- 忘记口令请联系系统维护人。

## 部署到 GitHub Pages（推荐）

本仓库已上传至 `https://github.com/ehabmarket16-create/Renjia-jifen`，按下列步骤即可开在线访问：

1. 打开仓库 **Settings → Pages**
   - Source 选 `Deploy from a branch`
   - Branch 选 `main`，目录选 `/ (root)` → **Save**
2. 等 1 分钟左右，访问 `https://ehabmarket16-create.github.io/Renjia-jifen/`

> 仓库设为 Public 时 Pages 免费可用；Private 仓库开 Pages 需要 GitHub Pro。
> 仓库根目录的 `index.html` 就是系统本体，改名或挪到子目录会导致 Pages 打不开。

## 功能一览

| 模块 | 说明 |
|---|---|
| 概览榜单 | 核算周期：全部 / 本周 / 本月 / 近 3 个月 / 近半年 / 近一年（并排按钮一键切换），显示真实起止日期、本周期笔数与分值、历史累计 |
| 积分录入 | 事项：宣讲·技能培训、读书分享达人、读书打卡（每周，默认 5 分）、运动打卡（每周，默认 2 分）、最佳检视者、创新型建议者、自定义；支持优/中/差档位与手工改分 |
| 人员管理 | 新增 / 停用 / 删除成员，可手工输入 |
| 礼品兑换 | 按人员扣减积分兑换礼品；**心愿墙**收集大家想要的礼物 |
| 积分流水 | 按 区间 / 人员 / 事项 / 关键词 多条件筛选，一键重置 |
| 兑换记录 | 历史兑换明细 |
| 规则说明 | 积分规则、兑换规则、数据管理（导出/导入 JSON、导出报表 MD / 明细 CSV） |
| 系统设置 | 各事项分值、默认核算周期；管理员密码为固定口令（只读说明） |
| 双角色 | **管理员**：全部权限；**访客**：只读（可填心愿墙），隐藏录入 / 人员 / 设置、数据管理与导出按钮 |

页头 LOGO 已 base64 内嵌，整套系统离线可用、单文件可分发。

## 重要说明

- **数据存在浏览器本地**（`localStorage`，键名 `jf_system_v1`）。换浏览器、换设备、清缓存后，数据不会自动跟过去。
  - 迁移办法：「规则说明 → 数据管理 → 导出全部数据 (JSON)」备份，再到目标设备「导入 JSON」。
- **部署到 GitHub Pages 后，每个访客看到的都是自己浏览器里的数据，彼此不互通**——这是纯前端单文件的固有限制。
  如果需要真正的多人共享同一份数据，必须接入后端 / 云数据库。
- **权限只是「防误操作」的轻量门禁，不是强安全机制。** 纯前端应用的代码全部可见，
  在浏览器开发者工具里一行代码就能绕过身份切换。要真正防住越权，必须接后端做校验。
  好处是：仓库里不含任何明文口令（只存哈希常量），公开托管不会直接泄露凭据。
